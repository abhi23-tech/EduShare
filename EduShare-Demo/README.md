# EduShare — Academic Resource Sharing Platform

EduShare is a peer-to-peer academic resource sharing web application designed for college students to upload, discover, search, filter, and access lecture notes, previous-year question papers (PYQs), reference materials, presentations (PPTs), and practical lab manuals.

---

## Key Features

- **Academic Materials Catalog:** Instant access to 2nd Year, 4th Semester Computer Science resources (Notes, Previous-Year Questions, Reference Materials, PPTs, and Lab Manuals).
- **Search & Multi-parameter Filtering:** Instant search across titles, subjects, topics, and departments with full department name display.
- **Resource Details & Material Access:** Detailed academic metadata overview and instant material access.
- **Resource Upload:** Upload lecture notes and study materials with subject tagging and academic year/semester classification.
- **My Uploaded Resources & Management:** Delete uploaded resources with confirmation prompts and real-time statistics updates.
- **Student Dashboard:** View student profile (*Aryan Sharma • Computer Science • 2nd Year • Semester 4*) with metrics for personal uploads and platform downloads.

## Getting Started

1. Navigate to the project directory:
   ```bash
   cd EduShare-Demo
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the application in your browser:
   ```
   http://localhost:5174
   ```
